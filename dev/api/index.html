BasisExpansions.BasisExpansions — Module
BasisExpansions

Represent values as linear combinations of basis vectors with trainable coefficients. BasisExpansion evaluates a basis matrix and its coefficients as an AbstractArray, with optional column-scaling or QR preconditioning.

Use get_coefficients and set_coefficients! to access or update coefficients in the original basis. polynomial_representation and complex_polynomial_representation construct polynomial expansions evaluated at supplied points.

source
BasisExpansions.BasisExpansion — Type
BasisExpansion(basis, coefs; precond = nothing)

Construct an array-like representation of basis * coefs with trainable coefficients. The input coefs are interpreted in the original basis.

Set precond to :column_scaling to scale each basis column to unit root-mean-square norm, or to :qr to use a thin QR factorization of a dense copy of the basis. QR preconditioning requires full column rank. The default, nothing, leaves the basis unchanged.

The resulting BasisExpansion behaves as an AbstractArray with the element type of basis * coefs and the row axis of basis. Inputs must have one-based indices, nonempty dimensions, and finite entries. Column scaling also requires nonzero basis columns. Use get_coefficients to retrieve coefficients in the original basis after optimization.

BasisExpansions.polynomial_representation — Function
polynomial_representation(evaluation_points, degree; precond = :qr)

Construct a polynomial BasisExpansion evaluated at the values in evaluation_points, using powers from zero through degree of the points shifted by their minimum. The coefficient vector has degree + 1 entries; its constant coefficient is initialized to the minimum evaluation point, and its linear coefficient is initialized to one when degree >= 2.

evaluation_points must be nonempty and finite. degree must be positive and no greater than the number of evaluation points. precond selects the preconditioning method used by BasisExpansion.

source
BasisExpansions.complex_polynomial_representation — Function
complex_polynomial_representation(evaluation_points, degree; precond = :qr)

Construct a complex-valued polynomial BasisExpansion evaluated at the values in evaluation_points. Its basis contains powers from zero through degree of the points shifted by their minimum, along with the corresponding imaginary basis columns. The coefficient vector has 2 * (degree + 1) real entries.

evaluation_points must be nonempty and finite. degree must be positive and no greater than the number of evaluation points. precond selects the preconditioning method used by BasisExpansion.

BasisExpansions.get_coefficients — Function
get_coefficients(representation)

Return the coefficients in the original basis. For a preconditioned representation, convert its current trainable coefficients back to the original basis.

source
BasisExpansions.set_coefficients! — Function
set_coefficients!(representation, coefs)

Set the coefficients in the original basis and return representation. For a preconditioned representation, convert them to the preconditioned coordinates before updating its trainable coefficients.
